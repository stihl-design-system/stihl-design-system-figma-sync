# Border Width

## Border Width

Border width tokens define the visual weight of borders across UI elements and ensure consistent stroke treatment throughout all components. Instead of hardcoding pixel values per component, two explicit width tokens are used, each tied to a specific use case.

**border-width-1** serves as the default for most components, while **border-width-2** is reserved for states that require higher visual emphasis, such as focus indicators.
