# Text Styles: App

## App Headings

Heading styles are used for primary headlines and section titles, providing clear hierarchy and visual prominence. Ideal for grabbing attention and structuring content.

Each heading size consists of two options to allow for maximum flexibility when creating hierarchies:

- uppercase
- lowercase

The **uppercase** variations should be given priority - specially for H1 and H2 headlines to convey the STIHL brand. Remember to keep **uppercase** headings short in order to guarantee legibility. For longer headings and to create multiple levels of hierarchy **lowercase** variations can be used.

> The new STIHL Font Digital has been implemented. Due to rendering issues with Figma, the font appears slightly off-center vertically, leaning towards the top.

> The app styles have not yet been integrated into the code library, so their mixins are not defined.

## App typescale usage in Core Components

Core components that are identical across both web and app follow the **web text style.** Since their values are the same, no distinction is needed. By using one single typescale, we avoid the use of themes for now.

This applies to the following components:

- Button
- Link
- Input
- Text Area
- Toast

## App Text

Text styles are primarily designed for body text in paragraphs and descriptions.

The minimum size for body text should not be smaller than Text M. Sizes smaller than Text M are best reserved for brief text elements, such as footnotes and hints.

## App Utility
