# STIHL Design System: design documentation from Figma

> Generated by `npm run sync` from the documentation pages of the STIHL Design System Figma libraries. Do not edit these files; the next sync overwrites them.

## How to use these files

- One Markdown file per documented page, grouped like the Figma team projects: `foundations/` (styles, typography, iconography, grid and spacing), `components/` (Core Components), `patterns/` (platform pattern libraries), `guidelines/` (onboarding and processes). Exported images live in a folder of the same name next to the file.
- `#` is the document title. `##` chapters follow the boards the designers laid out in Figma; `###` and `####` are their sections. Heading levels never skip, so a chapter can be fetched on its own by heading when the whole file is too long.
- The frontmatter carries the Figma source (`figmaFile`, `figmaProject`, `sourceUrl`, `figmaVersion`, `figmaVersionLabel`) and, where code components exist, `importNames` and `package` to look them up in Storybook, plus `keywords` for search.
- The documents cover design guidance: anatomy, sizing, content rules, do's and don'ts, behavior, use cases. Props, types and code examples are not in here; query the Storybook MCP server or `llms-full.txt` of the component library for those.
- Images are referenced relatively and have the section title as alt text, so the text stays meaningful without rendering them.
